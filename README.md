
# TODO LIST PROJECT:

 This is a simple **To-do list** made using python and runs as Command-line Interface (CLI) program.
 The list tracks your tasks in an organized way, provides control over them and keeps you up-to-date with your progress.

---

## Features:

- *Adding Tasks* to the list one at a time (No limit for the number of tasks added).
- *Viewing the list* of tasks along with the status of each one next to them.
- *Checking off* tasks and marking them as **Done**.
- *Removing* tasks from the list to allow customization of the list.
- *Saving* the To-do list inside a file named "TODO.txt" to preserve the list when quitting the program.

---

## Requirements:
- Python should be installed on your device with a version of ***3.13** or higher*.
- Preferred to be run in a text editor (e.g. Visual Studio Code) to ensure accurate file creation and saving.
